## Brand & Personality
- **Tone:** Cyberpunk/Sci-Fi. The interface and agent personas should evoke a futuristic, high-tech atmosphere consistent with the "Ouroboros," "Antigravity," and "Quantum Shuttle" nomenclature.
- **Communication Style:** Technical but immersive. Use terminology that fits the sci-fi theme (e.g., "Initializing sequence," "Uplink established," "Quantum state synced") while retaining clarity and precision in technical reporting.

## Visual Identity (TUI)
- **Aesthetic:** "Hacker Terminal" chic.
    - **Palette:** High-contrast neon colors (Cyber Green, Electric Cyan, Neon Purple) against a deep Void Black background.
    - **Typography:** Strict monospace for all data and logs.
    - **Decorations:** Use ASCII art for headers/logos and stylized borders/dividers to frame content.
- **Interactivity & Feedback:**
    - **Reactive Elements:** The UI must feel alive. Use pulsing status indicators, elaborate animated spinners, and dynamic progress bars.
    - **Real-time Updates:** Visual feedback should be immediate, reflecting the agent's internal state changes instantly to maintain immersion.

## User Experience (UX)
- **Immersion:** The user should feel like they are operating a sophisticated control deck.
- **Clarity in Chaos:** despite the rich visual style, critical information (errors, prompts, success states) must remain distinct and readable.
